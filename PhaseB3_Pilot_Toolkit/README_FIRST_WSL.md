# ARCO Revision-I — Phase B3 pilot selection (beginner WSL guide)

**Current stage:** Phase B1 v1.2 was author-ratified; B2 initial registers exist, with **21,825 NOT_ASSESSED slots** and **no new codes**. This package selects (does not code) the 40 pilot studies. It checks the actual B2 initialization receipt and hashes. It does **not** change the frozen XLSX, the signed B1 package, or initialized B2 files.

## A. Extract toolkit

Download `ARCO_PhaseB3_Pilot_Selection_Kit_20261029.zip` to the root of your project, then in WSL Ubuntu:

```bash
cd ~/projects/Stock_Price_Prediction_SLR_ACME
conda activate Harman_GPU
unzip -o ARCO_PhaseB3_Pilot_Selection_Kit_20261029.zip -d PhaseB3_Pilot_Toolkit
```

## B. Preflight ONLY — no files written

```bash
python PhaseB3_Pilot_Toolkit/select_b3_pilot_40.py \
  --b2-dir ./PhaseB2_Initialized_v1 \
  --output-dir ./PhaseB3_Pilot_Selected_v1 \
  --seed 20261029 \
  --preflight
```

Expected: `B2 AUTHORIZATION AND INTEGRITY: PASS`, evidence-scope quotas `30/6/4`, 11 family quotas satisfied, `STATUS: B3_PREFLIGHT_PASS__NO_FILES_WRITTEN`.

## C. Select the fixed 40 cases

If preflight passes:

```bash
python PhaseB3_Pilot_Toolkit/select_b3_pilot_40.py \
  --b2-dir ./PhaseB2_Initialized_v1 \
  --output-dir ./PhaseB3_Pilot_Selected_v1 \
  --seed 20261029
```

Expected: `STATUS: B3_PILOT_SELECTION_PREPARED__AUTHOR_REVIEW_PENDING`, and `NEW EVIDENCE CODES: 0`. It will refuse to overwrite an existing selection folder. To revise the selection, preserve the old folder and use a **new versioned output path** with an explanatory protocol-amendment log.

## D. Inspect the results

```bash
code PhaseB3_Pilot_Selected_v1/B3_pilot_40_SELECTION_LOCKED_PENDING_AUTHOR.csv
code PhaseB3_Pilot_Selected_v1/B3_pilot_40_STRATA_SUMMARY.csv
code PhaseB3_Pilot_Selected_v1/B3_SELECTION_MANIFEST.json
code PhaseB3_Pilot_Selected_v1/B3_pilot_40_AUTHOR_SELECTION_REVIEW.csv
```

1. Check there are **40 unique Paper_IDs**.
2. Check **30 Full_Text**, **6 Abstract_Only**, **4 Metadata_Only**.
3. Check the 11 prescribed full-text method-family quotas (7 deep, 6 hybrid, 4 sentiment, 4 transformer, 3 metaheuristic and one each of the remaining six families).
4. Examine the seeded selection and legacy stratification coverage in `B3_SELECTION_MANIFEST.json`. Legacy Phase A values are **sampling aids, not independently verified findings**.
5. Review the 40 IDs; in `B3_pilot_40_AUTHOR_SELECTION_REVIEW.csv` record actual author decisions only after checking eligibility and the pilot design. No approval is autogenerated.
6. Use `B3_pilot_40_SOURCE_ACQUISITION_CHECKLIST.csv` to locate and confirm each actual primary paper, title/DOI match, source SHA-256 and access status. Full_Text in Phase A does **not** prove that its PDF is currently present locally.
7. Do not begin paper-specific YES/NO/LOW/HIGH coding without accessible original sources and claim-specific evidence logging.

## Important scientific limitations

- The sample is **purposively stratified for rule calibration**; it is not representative for estimating evidence prevalence or error rates.
- Selecting the first seeded draw that meets prospective coverage constraints is deterministic, but deliberately **not a simple random sample**. The manifest records the seed, draw number and criteria.
- Two full-text method families contain only one eligible paper; those are selected with certainty.
- The historical leakage and validation categories in the frozen register are **unverified sampling labels** and cannot count as Phase B evidence.
- B3 does **not** replace the independent, separately sampled Phase C reviewer-reliability study requested by Reviewer 1.
- All original Phase A data, present manuscript numbers, and B2 initialization records remain frozen pending verified B-phase evidence and Phase C.
